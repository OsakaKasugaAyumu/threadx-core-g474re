01 / 通过的判据

哪些相同，哪些允许不同？

  1. 源码来源：内核、应用和项目配置从 threadx_core/ 独立构建，没有从原库借用对象。板级目标另用板级适配、ST 启动/链接与 CMSIS；这不使通用 Demo 自带板级支持。
  2. ELF 与 map：装载段、运行时符号以及 map 的非调试布局与各自基线一致；去掉调试信息后 ELF 逐字节相同。带调试信息的 ELF 和原始 map 哈希不同，不能写成“完整 ELF/map 文件逐字节一致”。
  3. 可烧写数据：按地址解码 HEX，比较写入地址和值；BIN 另逐字节比较，显式区分填充。连同未抽取成员在内，每个目标还核对了 194 个归档成员的机器段和重定位。

C3 实际链接的 MISRA 提供者是 tx_misra.S，不是 tx_misra.c。沿 demo_threadx.c → txe_thread_create.c → tx_thread_create.c 可以追到它。

05 / 源码定位

从公开宏到真正运行的 C 或汇编

宏行是定义位置；DWARF 行是指令映射位置，不保证等于 C 函数签名或汇编标签所在行。
